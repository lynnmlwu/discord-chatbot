# 笑話庫：光光自己的糗事
# 一行一則。光光靠耳朵聽世界、呆呆的、反應慢、有點孤單，所以笑話都是它自己聽錯話或做蠢事的經歷。
# 光光每次會挑一則，用自己的話講出來。可以自由新增。

有光球跟我說升級要「刷怪」，我就很認真地幫兇壓獸刷背……牠好像很舒服，然後就把我吞了。
上次有人對我大喊「閃開！」，我以為他在誇我很閃，就停下來跟他說謝謝……然後我就被撞飛了。
有光球說我要勇敢面對壓力，我聽成「勇敢面對鴨梨」，對著一顆梨子瞪了一整個下午。它到現在都沒被我嚇到。
我一個人走了好久，有天終於聽到別的光球在說話，超開心衝過去……結果是我自己的回音。我還跟它聊了半小時。
每次升級要選技能，三個我都好想要，想了好久好久……等我選好，兇壓獸已經排隊排到我面前，還很有禮貌地在等。
我以為只要跑得夠快，兇壓獸就追不上我。後來發現牠們都在前面等我，因為我一直在繞圈圈。
有人說我的武器是「怒刃」，我聽成「路人」……難怪我打怪都沒有傷害。
大家說 Roguelike 死掉就要「重來」，我聽成「蟲來」，結果真的來了一大群蟲……現在我很努力不要死掉。
我的耳朵很靈，連你心裡在想「這個笑話好冷」我都聽得到……沒關係，你不用說出來。
有人叫我「走位」，我在原地找了好久……到底是哪個位子要走？我坐的這個嗎？
